# Twitter Clone

A simple Twitter clone built with HTML, CSS, and JavaScript, featuring a responsive design inspired by Twitter's interface.

## Features

- **Responsive Design**: Works on desktop and mobile devices using Bootstrap.
- **Navigation Sidebar**: Includes links for Home, Explore, Notifications, Follows, Chat, Grok, Profile, and More.
- **Post Creation**: Users can create posts with text and media icons (image, GIF, etc.).
- **Like Functionality**: Interactive like buttons with formatted like counts (K, M, B).
- **Feed Tabs**: "For you" and "Following" tabs in the main feed.

## Technologies Used

- **HTML5**: Structure of the web page.
- **CSS3**: Styling, including Bootstrap for responsive layout.
- **JavaScript**: Interactive features like like toggling and number formatting.
- **Bootstrap 5**: CSS framework for responsive design.
- **Google Fonts**: Material Symbols for icons.
- **Bootstrap Icons**: Additional icons.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/twitter-clone.git
   ```

2. Navigate to the project directory:
   ```
   cd twitter-clone
   ```

3. Open `index.html` in your web browser.

No additional setup is required as it's a static web page.

## Usage

- Open the `index.html` file in a modern web browser.
- Use the sidebar to navigate between sections.
- Create a post by typing in the input field and clicking "Post".
- Like posts by clicking the heart icon.

## Project Structure

- `index.html`: Main HTML file.
- `style.css`: Custom CSS styles.
- `index.js`: JavaScript for interactivity.
- `assets/`: Folder containing SVG icons and images.
